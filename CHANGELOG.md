# Changelog

## 1.0.0
- Resizable, monochrome home-screen media widget for every media app (via media sessions).
- Circular colour thumbnail, "Playing on <app>" label, title, progress bar with elapsed/total time.
- Play/pause, rewind/forward (seek) or previous/next track.
- Tap the widget to open the playing app.
- Settings page: transparency, frost tint, corner radius, theme, refresh speed, button behaviour.
- Instant play/pause feedback; progress ticks on a configurable interval.
